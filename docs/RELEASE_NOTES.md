# MaaNightfall v0.2.3

- 契约之刃加入兑换列表首项：特供商店每周 2 个，家族每周 1 个；沿用价格、额度、数量与余额校验。
- 默认体力计划改为欲望酒会 X 3 次，再用当天一种家族遗迹消耗剩余体力。地牢血痕、密室残垣、市井焦土、古堡回声每天一种，四天循环；从 2026-10-09 开始按上海自然日计算，同一天重复运行保持同一种。
- 秘密派遣支持免费刷新 2 级金币或经验书任务。先派出特殊红色、5 级、3 级、信封、结晶及识别不清的任务；每次刷新必须确认“免费刷新”和剩余次数，结果未确认时不重复点击。
- 修正据点领取按钮范围，领取后继续检查巡逻惊喜；家族遗藏不点击。
- 修复启动加载等待、好友赠礼退出、通行证入口、兑换页签和简报选择/奖励/退出等流程问题。
- 命令行逐模块执行并记录失败，某个模块失败后重新启动游戏，再从下一模块继续；缄默暗门按固定 15 天一期判断。
- 优化所选 MuMu 实例冷启动处理，并同步源码、GUI 与发行包版本号。

Windows 用户下载 MaaNightfall-v0.2.3-win-x86_64.zip，解压后双击 MaaNightfall.exe。升级时保留 config/ 与 .state/，重新打开助手加载新流程；原默认关卡选项现在对应上述日常体力计划。

验证：兑换与据点截图回放、真实派遣图标识别和四行指派回放，以及免费刷新保护、四天体力轮换、GUI、模块恢复、周额度和配置校验。免费刷新后的页面使用模拟测试；本次未实机消耗体力、兑换或刷新次数，尚未验证完整日常连续执行。

发行包不包含作者的模拟器绑定、账号状态、日志、每日关机脚本或 QQ 凭证。
