# MaaNightfall v0.2.4

- 修复体力超过自然恢复上限时停止扫荡的问题。270/240 等合法体力余额现在可正常执行计划，仍会校验扫荡次数和实际消耗。
- 修复据点再次生产后重复点击“一键领取”、误入制作清单并导致超时的问题。每轮只领取一次，确认返回据点后继续巡逻惊喜和订单；进入制作清单时会返回据点。

Windows 用户下载 `MaaNightfall-v0.2.4-win-x86_64.zip`，解压后双击 `MaaNightfall.exe`。升级时保留 `config/` 与 `.state/`，重新打开助手加载修复。

验证：2026-10-09 两张错误截图的原生 MaaFramework 回放、残留领取按钮防重复点击、超上限体力分批扫荡、体力轮换与消耗校验、据点订单退出、GUI 版本检查、资源加载与 JSON Schema 校验。完整日常实机连续执行尚待验证。
